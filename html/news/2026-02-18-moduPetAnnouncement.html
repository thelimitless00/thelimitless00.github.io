ModuPet Announcement

February 18, 2026

Hey! Glad you stopped by!

Today I'm announcing my current project; ModuPet.

ModuPet is a virtual pet simulator that can run on nearly any device! It's still being programmed and does not have full functionality yet, but the project is coming along nicely.

ModuPet is currently available on GitHub, and you can download and set it up later when I have full releases set up.


Personally, I'm really excited about this project. Virtual pets are a very nostalgic thing for me, and to design my own has been a huge walk down memory lane. I hope to bring the best in the virtual pet industry to this project, and I'm hoping you all can enjoy it soon!
